# Motion Spot

Android app: a splash screen (Khorfakkan and Fujairah drivers, created by ਤਜ਼ਰਬੇਕਾਰ), then a camera view where you draw a box. If movement is seen inside it, a Yelp siren plays.

Build: push this folder to GitHub (the included workflow builds the APK and attaches it to a Release), or open in Android Studio and run Build > Build APK.
Keep the app open and the phone steady while watching.
